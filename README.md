# dbf-mods
Repository of Discord Bot Factory mods


Each mod must be installed in your bot's project folder as

`.\mods\(modfolder)`

Project also contains a agent skill to develop custom mods with agentic coding tools (Antigravity, Codex, Claude Code) or general reference.

**IT IS RECOMMENDED TO BACKUP YOUR PROJECT PRIOR TO INSTALLING/UPDATING MODS**
I do my best to test each node created, however I am not responsible for any damage done to your project, if issues arise please create an Issue or Pull Request.
